# AI-design-PaperBox

纸盒包装创意工作台与 Ohuhu 72 色酒精马克笔纸盒方案。

## 在线网站

GitHub Pages 发布后，网站地址为：

`https://yifengxiong43-prog.github.io/AI-design-PaperBox/`

网站入口文件在 [`docs/index.html`](docs/index.html)，包含 C v13 方案的结构组成、取笔动图、尺寸账本、材料装配说明和待验证项目。

## 仓库内容

- `desktop/`：原生 WPF 纸盒包装创意工作台源码。
- `docs/`：GitHub Pages 静态网站及 C v13 图片、动图和模型文件。
- `project/`：C v13 的设计说明、交付记录和复现脚本。

纸盒结构仍是概念模型，纸板厚度、铰链寿命、抽拉间隙和闭合保持力需要通过白样继续验证。
