# V1.0.0 验证记录

## 本次升级

- 单主 Agent 编排资料检索、需求理解、reference 图片约束提取、方案草拟、确定性几何、制造引用校验、独立复核、图片生成和图片质量检查。
- 随包 Python 3.12.10 `decimal` 工具独立复核笔组单排宽度、完整笔长、三轴尺寸和支数；C# 账本继续计算外壳与展开包络。
- 本轮资料使用 `CitationCatalog` 短编号；程序绑定稳定资料 ID、正文哈希和原文摘录，模型不能编造路径、UUID 或 Quote。
- 图片质量修正和 API 请求均有上限；同一视图最多 3 次图片请求，失败后保留待修正结果和原因。
- Agent 工具调用写入 `%LOCALAPPDATA%/PaperStudio/agent-runs.jsonl`，资料错误写入 `reference-errors.jsonl`。日志不包含密钥、完整 prompt、响应正文或图片数据。
