# 纸间 V0.6 · Minimalist Premium

原生 WPF 工作台，视觉参考 Linear，创作流程参考 Krea。没有复制二者源码。

## 统一资源

`resources/DesignSystem.xaml` 由应用启动时加载。主窗口、API 设置及导出菜单共用资源。

| Token | 值 | 用途 |
| --- | --- | --- |
| Canvas | #FAFAF9 | 创作区域 |
| Surface | #FFFFFF | 输入面板、图片底色 |
| Ink | #1C1C1C | 正文 |
| Muted | #8A8A8A | 次要说明 |
| Line | #EAEAEA | 分割线、输入边界 |
| Accent | #202521 | 生成与修改操作 |

布局间距以 8 / 16 / 24 px 为主；控件圆角 8 px，图片、工具栏与输入浮层 12 px。字体声明 Inter → Microsoft YaHei UI → Segoe UI；未安装 Inter 时使用系统字体。图标使用 Lucide 的 Box、Settings-2、Arrow-up、Chevron、X 等路径，转换为 WPF Geometry；授权保留于 `resources/LUCIDE-LICENSE.txt` 并随构建复制。

按钮、文本输入、密码、下拉框（含可编辑模型 ID）、折叠栏、滚动条和导出菜单使用自定义模板。保留禁用、悬停和键盘焦点状态，不依赖系统默认控件外观。

## 信息层级

- 顶栏 56 px：品牌、创作 / 项目、保存 / 导出 / API 设置。
- 左栏 320 px：自然语言需求置顶；产品参数、包装尺寸、材料与补充要求、参考图片分别折叠；生成按钮固定在底部。
- 默认只显示三方向概览。点击图片卡片后进入大图预览，并展开 280 px 详情栏与修改输入框。对比、关闭详情或创作导航返回概览。
- 底部工具保留缩放、视图菜单、对比；重新生成收进更多菜单。旧版的全部视图、版本、导出与可行性信息均保留。
- 宽度低于 1280 px 时，概览改为纵向大图。详情预览根据可用空间自适应，放大后可拖动。

展示状态 `detailOpen` 只在内存中使用，未改变项目数据格式、API 协议或提示词逻辑。

## 验证

`test.ps1` 验证原有业务。QA 构建的 `--render-check` 验证三方向选择、详情显隐、视图菜单、缩放、版本恢复、旧方案缺失尺寸、可编辑模型 ID、资料传入及窗口控件边界。

检查尺寸：1080×720、1366×768、1380×920、1536×864（WPF 逻辑像素）。这不是跨显示器 DPI 切换实测。截图使用已有草图作为 QA 响应，明确标为 QA 方案，不代表新生成效果图。正式构建不含测试响应代码。
